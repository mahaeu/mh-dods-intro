# DODS Notebooks (Starter + Analyzer Intro)
This is an introduction to **two separate packages** bundled in the **dods** module:
- **dods-datagen** (generate datasets from YAML templates)
- **dods-analyze** (quick analysis: distributions, anomalies, and feature relationships)

Both notebooks can be run without edits. Just run the **first notebook** before the **second** (`02_dods_analyze.ipynb`) to generate data to analyze.  
In the second notebook (`02_dods_analyze.ipynb`), if you enjoy exploring the analysis, feel free to also load your own CSV datasets and experiment with different data.
Setup is minimal and described at the bottom (create a venv and `pip install dods jupyterlab`).

### dods-datagen
An easy to use package for easy synthetic data generation. Data can be generated by writing a **.yaml** file and minimal code. Package internal templates can be used, manually written or generated via AI.
Short code snippet
```python
import dods.datagen as dg     # Import the package

# Optional creation of a short or long template (.yaml file). 
# Use 1 option of the options:
dg.create_template()                   # Default value (dg.create_template('template'))
dg.create_template('template_long')    # Long template to see full capabilities

# Create the Data
dg.run('template')
```
This creates a **.csv** file with data. The output path is set in the **.yaml** file.

### dods-analyze
This package makes first investigations of datasets easy. It can give an overall overview, analysis of numerical/categorical data or analyze the relationships between columns/features.

Short code snippet

```python
from dods.analyze import DataAnalyzer
import pandas as pd

# Load a .csv file
df = pd.read_csv('data/template.csv')

# Run the package for analysis and save it in a variable (dfa)
dfa = DataAnalyzer(df)

# Use the Analysis methods
dfa.summary()
dfa.analyze_distributions()
dfa.analyze_categoricals()
dfa.analyze_relations()
dfa.analyze_missing()
dfa.analyze_outliers()
```

Optional Parameters are described at the end of the output of
```dfa.summary()```

## Installation
Installing the packages is the same for any other python pagkage, by using ```pip install dods```, ```pip install dods-datagen``` or ```pip install dods-analyzer```.

You should follow the general workflow of creating a virtual environment, activating it and then installing the mentioned packages.
